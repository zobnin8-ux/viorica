# Viorica Cazac — первый рабочий прототип

Статический двуязычный сайт (RU/RO): главная + 8 направлений на каждом языке. Адаптивная верстка, оригинальные фотографии, сертификат, заглушки до получения авторских текстов.

## Запуск локально

Из папки `viorica-site`: `python -m http.server 8000`, затем открыть `http://localhost:8000/ru/`.

## Размещение на Cloudflare

1. Загрузить проект в GitHub-репозиторий, принадлежащий заказчице (или передать ей доступ).
2. Cloudflare → Workers & Pages → Create → Pages → Connect to Git.
3. Framework preset: **None**, Build command: **пусто**, Build output directory: **/** (корень проекта). При использовании панели, требующей отдельной директории, перенесите статические файлы в `public` и укажите `public` как output, а папку `functions` оставьте в корне репозитория.
4. В Pages → Settings → Variables and Secrets добавить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` как секреты; до этого отправка формы будет показывать ошибку.
5. Подключить собственный домен после утверждения проекта.

## Статус

- Тексты направлений, биография, цены, условия сессий, контакты, румынские переводы подлежат согласованию. Румынские названия направлений предварительные, а описания — заглушки.
- Домен, аккаунт Cloudflare, GitHub и Telegram-бот должны контролироваться заказчицей.
- Форма требует проверки после подключения Telegram; не публиковать как работающую до этого.
- `build.py` генерирует HTML-страницы, готовые страницы уже включены в архив.
