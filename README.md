# Viorica Cazac — рабочая версия сайта

Статический адаптивный сайт на Vercel: главная, восемь основных направлений на RU/RO, дополнительные русскоязычные страницы практик (космоэнергетика, ангелотерапия, работа с субличностями, работа с родом, ДПДГ/EMDR, месмеризм, регрессионная гипнотерапия), раздел «Обо мне», форма записи в Telegram через Vercel Serverless Function.

**Статус:** рабочая версия для просмотра, не окончательная публикация. Русскоязычные тексты в дополнительных разделах **редакторски сокращены** по материалам заказчицы; для дословного размещения потребуется сверка и импорт полных оригиналов. Румынские переводы текстов ещё не предоставлены заказчицей; опубликованные RO-страницы содержат предварительные названия и временные тексты. Не заявлять их как утверждённый перевод.

## Локальный просмотр

`python -m http.server 8000`, открыть `http://localhost:8000/ru/`.

## Vercel

Сайт: https://viorica.vercel.app, GitHub `zobnin8-ux/viorica`, Production — ветка `main`. Статические страницы размещены в корне, обработчик формы — `api/booking.js`.

В Vercel Production необходимы переменные `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`. После изменения переменных требуется Production-деплой. Не публиковать секреты в репозитории.

Перед передачей клиентке проверить RU/RO, ссылки, мобильную версию и тестовую заявку.

`build.py` — исходный генератор первого прототипа; `extend.py` — расширение страниц. Готовые HTML-файлы уже включены, поэтому для статического деплоя Python не нужен. При повторном выполнении скриптов запускать **сначала `build.py`, затем `extend.py`**.
