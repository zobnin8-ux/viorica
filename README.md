# Viorica Cazac — рабочая версия сайта

Статический адаптивный сайт на Cloudflare Pages: главная, восемь основных направлений на RU/RO, дополнительные русскоязычные страницы практик (космоэнергетика, ангелотерапия, работа с субличностями, работа с родом, ДПДГ/EMDR, месмеризм, регрессионная гипнотерапия), раздел «Обо мне», форма записи в Telegram через Cloudflare Pages Function.

**Статус:** рабочая версия для просмотра, не окончательная публикация. Русскоязычные тексты в дополнительных разделах **редакторски сокращены** по материалам заказчицы; для дословного размещения потребуется сверка и импорт полных оригиналов. Румынские переводы текстов ещё не предоставлены заказчицей; опубликованные RO-страницы содержат предварительные названия и временные тексты. Не заявлять их как утверждённый перевод.

## Локальный просмотр

`python -m http.server 8000`, открыть `http://localhost:8000/ru/`.

## Cloudflare Pages

1. Подключить репозиторий к Cloudflare Pages. Build command оставить пустым; output directory — корень проекта `/` (если интерфейс не поддерживает корень, переместить статические страницы в `public`, сохранив `functions` в корне).
2. Добавить секреты `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` для отправки заявок. Пока секреты не настроены, форма вернёт ошибку и заявка не будет доставлена.
3. Протестировать форму, адаптивность, ссылки, сертификаты и тексты до публикации.
4. Домен, Cloudflare, GitHub и бот должны находиться под контролем заказчицы.

`build.py` — исходный генератор первого прототипа; `extend.py` — расширение страниц. Готовые HTML-файлы уже включены, поэтому для статического деплоя Python не нужен. При повторном выполнении скриптов запускать **сначала `build.py`, затем `extend.py`**.
