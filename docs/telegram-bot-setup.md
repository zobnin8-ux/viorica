# Настройка Telegram-уведомлений — Viorica Cazac

Сайт уже содержит форму на `/ru/` и `/ro/`, которая отправляет заявку на серверный маршрут `/api/booking`. Он пересылает уведомление в Telegram через Bot API. **Токен бота не должен появляться в GitHub, в браузере или в публичном чате.**

## Что нужно сделать перед запуском

1. Виорика создаёт бота через [@BotFather](https://t.me/BotFather), получает токен и сохраняет его конфиденциально.
2. Виорика открывает диалог с созданным ботом и нажимает **Start**. Бот не может первым написать пользователю.
3. Узнать числовой chat ID можно через безопасный инструмент администрирования бота или метод `getUpdates` с токеном **только в защищённой среде**. Не публиковать URL с токеном и ответы API.
4. В настройках проекта Vercel → Settings → Environment Variables добавить `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` для Production (и Preview при необходимости). Не добавлять значения в репозиторий.
5. После снятия ограничения деплоев выполнить **один** деплой из подготовленных изменений и проверить тестовую заявку. Убедиться, что пришло уведомление, и что форма показывает успех только после ответа Telegram.

## Проверки

- RU и RO: имя и контакт обязательны; чекбокс согласия обязателен.
- Запрос без `consent=yes` сервер отклоняет с 400.
- При отсутствии переменных сервер возвращает 503; интерфейс сообщает об ошибке и предлагает написать напрямую в [@viorica_cazac](https://t.me/viorica_cazac).
- Тестировать с вымышленными данными; не вводить диагнозы и чувствительные сведения.
- В уведомлении передаются имя, контакт, направление и комментарий. Для безопасной обработки настоящих заявок необходимо согласовать хранение и доступ к чату.
